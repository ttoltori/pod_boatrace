## 4. 投票金額の分配戦略

### 4.1 期待値ベース配分（推奨）

期待値（`expect_bor`）に比例して投票金額を調整する戦略：

```
投票金額 = 基準金額 × expect_bor
```

**戦略Aに期待値ベース配分を適用した場合:**
- 総投票金額: 32,338円
- 総払戻金額: 61,362円
- **利益: +29,024円**
- **回収率: 189.75%**

### 4.2 固定金額戦略

すべてのベットに同額（100円）を投票する単純な戦略。
- メリット: 管理が簡単
- デメリット: 期待値の高いレースで機会損失

## 5. 推奨投票フロー

```
1. 風速チェック
   └─ wind > 2m → 投票しない
   └─ wind <= 2m → 次へ

2. 条件チェック（いずれかを満たす）
   ├─ A級選手数が0, 5, 6人 AND オッズ人気度5位以内
   ├─ 1号艇がB1級 AND オッズ人気度5位以内
   ├─ グレードレース(G1/G2/G3/SG) AND オッズ人気度5位以内
   └─ オッズ人気度が[1-7,12,13,16,26-28]のいずれか AND 期待値1.0以上

3. 投票金額決定
   └─ 基準金額 × expect_bor
```

## 6. リスク管理

### 6.1 月間変動
- 最良戦略でも月間黒字率は約70%（13ヶ月中9ヶ月が黒字）
- 3-4ヶ月連続で赤字になる可能性あり
- **資金管理**: 最低3ヶ月分の損失に耐えられる資金を確保

### 6.2 サンプルサイズの注意
- 戦略A: 280回（月平均約22回）
- 戦略B: 243回（月平均約19回）
- 投票機会が限られるため、条件を満たすレースを見逃さないことが重要
